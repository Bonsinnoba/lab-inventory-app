# LabOS

LabOS connects laboratory projects, tasks, experiments, inventory, resources, notebooks, canvas and financial evidence in one desktop workspace. The Tauri/React client uses native local storage and an outbox; the API owns central PostgreSQL authorization/synchronization. Desktop never connects directly to PostgreSQL.

Personal-lab **V1 2.2.5** is installed. V2 **Phase 2 remains in progress**. Implemented source, installed releases and completed acceptance are distinct.
